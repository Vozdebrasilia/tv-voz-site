# VOZ NEWS TOP 10 Portals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Conectar os cinco portais existentes aos respectivos módulos TOP 10, completar seus contratos editoriais e criar os cinco módulos restantes.

**Architecture:** Manter o site estático atual e suas rotas públicas. O `top10-runtime.js` passa a encaminhar módulos completos diretamente às rotas ricas; novos módulos usam páginas independentes com conteúdo e pesquisa local, preservando as páginas editoriais já existentes.

**Tech Stack:** HTML, CSS e JavaScript estáticos; testes Node.js; hospedagem Vercel via Git.

**Spec:** `docs/superpowers/specs/2026-09-07-top10-portais-design.md`

## Global Constraints

- Não alterar ou recriar nenhuma logomarca.
- Todo portal deve ter links, entrevistas, pesquisa/consulta e empresas correlatas.
- Preservar as rotas e o conteúdo dos cinco portais existentes.
- Manter o estúdio aprovado arquivado e fora do site público.
