# Provocative Analysis and SEO Design

## Editorial voice
Each article is analyzed by one journalist only, alternating automatically between Dra. Deijanete Fayad and Paulo Fayad. The writing style is intentionally strong, provocative, human, polemical, and columnist-like, with a clear point of view. It should include a sharp opening, contradictions, political stakes, who gains/loses, uncomfortable questions, strategic implications, and a forceful conclusion. Facts, polling numbers, official statements, court decisions, dates, and statistics must remain distinguishable from opinion and must cite sources when used. No fabricated claims.

## Avatar card branding
Do not create a new VOZ NEWS logo. Reuse the exact same logo asset already used in the site header. Place that asset centered in the white strip of the active analyst card with preserved aspect ratio (`object-fit: contain`) and no stretching, distortion, recoloring, or regeneration. Only the active analyst for the current headline is shown in the feature area.

## SEO/indexing direction
Each analysis should ultimately have its own crawlable URL, title, meta description, canonical URL, author, publication/update dates, internal links, NewsArticle/Article structured data, and sitemap entry. Author identity should clearly distinguish Deijanete and Paulo. Social metadata should support sharing to WhatsApp, Facebook, X, LinkedIn, and other networks while linking back to the canonical VOZ NEWS article.

## Constraints
- Preserve the current V33 visual identity and existing headline feed.
- Use the existing header logo asset; never generate a substitute.
- Keep Deijanete identified as Journalist.
- Keep one analyst per story, alternating 50/50.
- Maintain explicit sourcing for verifiable claims.
